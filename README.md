### Hi, I'm Terry

Product manager and builder in Dublin. I run **VRIM**, an AI consultancy and product studio, and I write a lot of the code myself: native mobile, web, backend, infra, and the odd ESP32.

20+ years across telco, smart energy and immersive media. Three patents, CISSP, BEng from UCD.

**Full portfolio:** [github.com/TerVRI/portfolio](https://github.com/TerVRI/portfolio) · **Contact:** terry@vr.ie · [LinkedIn](https://linkedin.com/in/terry-madigan-43117618)
